## What it covers

- Product search volume
- Best sellers
- Best sellers by category

| Data | Ask with | What it measures |
|---|---|---|
| History and growth | a keyword: product name or category | Amazon product search volume |
| Live board: Amazon Best Sellers Top Rated | no keyword | Amazon top-rated best sellers across all categories |
| Live board: Amazon Best Sellers by Category | no keyword | Amazon best sellers filtered by product category |

## How to ask

Pass a product name or category for search volume. The top-rated best-seller list needs no keyword. The category best-seller list needs a category name, such as Toys Games.

**Good to know:** This is search interest and the best-seller lists. It does not return prices, stock, or reviews.

## FAQ

**Does the Amazon connector return prices?**  
No. It returns product search volume, plus best-seller lists.

**Can I see best sellers in one category?**  
Yes. Best sellers can be read overall or split by category, with no keyword.

**Is the Amazon connector free?**  
Yes. The free plan has 100 requests a month and includes every source. No credit card. Paid plans start at $19 a month for 1,000 requests.

**Which AI apps work with it?**  
Claude, ChatGPT, Cursor, VS Code, Claude Code, Grok, Muse, Perplexity, Gemini, Copilot, Windsurf and any app that supports MCP connectors.
